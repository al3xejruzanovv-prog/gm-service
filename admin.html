Как подключить админку
  1. Создайте бесплатный проект на supabase.com.
  2. В SQL Editor выполните скрипт supabase/schema.sql из репозитория.
  3. В Authentication → Users создайте администратора (e-mail и пароль).
  4. Вставьте Project URL и anon key в assets/js/config.js.

Подробная инструкция — в файле README-admin.md.
