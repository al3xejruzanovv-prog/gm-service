# Админка сайта G-M Service

Сайт — статический (GitHub Pages), поэтому «настоящий» вход и хранение
правок вынесены во внешний сервис **Supabase**. Это даёт:

- реальную авторизацию по e-mail и паролю (пароли хранит Supabase, не сайт);
- сохранение правок в базе данных — их видят все посетители;
- защиту записи через Row Level Security (RLS): читать может любой,
  менять — только вошедший администратор.

## Статус

Проект Supabase уже создан, таблица `page_content` и политики RLS применены,
самостоятельная регистрация отключена, а URL и publishable key прописаны в
`assets/js/config.js`. Админка готова к использованию: `/admin.html`.

## Как это работает

1. Администратор открывает `https://<сайт>/admin.html` и входит.
2. Его перебрасывает на `index.html?edit=1` — включается режим правки.
3. Любой текст, цена или заголовок становятся редактируемыми.
4. Кнопка **«Сохранить»** (или `Ctrl+S`) записывает изменения в Supabase.
5. `assets/js/cms.js` на каждой странице подгружает сохранённые правки
   и подставляет их посетителям.

## Использование

- Вход: `https://<сайт>/admin.html`
- Редактирование: после входа откроется главная с панелью внизу.
- Переключение страниц — выпадающий список в панели.
- **Сохранить** — записать правки (появляются у всех).
- **Сбросить правки** — удалить все правки текущей страницы.
- **Выйти из режима** — посмотреть страницу как посетитель.
- **Выйти из аккаунта** — завершить сессию.

## Важные ограничения

- Ключ правки привязан к порядку блоков на странице. Если сильно менять
  HTML-структуру страницы (добавлять/удалять абзацы в коде), старые
  правки могут «съехать» на соседние блоки. В этом случае нажмите
  «Сбросить правки» и отредактируйте заново.
- Редактируется только контент внутри страницы: шапка, подвал и меню
  защищены от правок.
- HTML сохраняется как есть (админ — доверенный пользователь). Не
  вставляйте скрипты из недоверенных источников.
- Если `config.js` не заполнен, сайт работает как обычно, а `admin.html`
  показывает инструкцию.

## Файлы

| Файл | Назначение |
| --- | --- |
| `admin.html` | Страница входа |
| `assets/js/config.js` | URL и anon key Supabase |
| `assets/js/cms.js` | Загрузка правок + режим редактирования |
| `assets/js/admin.js` | Логика формы входа |
| `supabase/schema.sql` | Таблица и политики доступа |
